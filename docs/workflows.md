# Workflows

## Guest
Homepage → Catalog → Auction Detail → Participants.

## Onboarding
Register → OTP → Profile → KYC → Dashboard.

## Auction
Detail → Registration → Eligibility → Live Room → Manual Bid / Auto Bid → realtime update → Result.

## Winner
Result pending → provisional winner → confirmation → payment obligation → reconciliation → handover → review.

`CLOSED` chỉ kết thúc nhận bid, không tự động đồng nghĩa `CONFIRMED_WINNER`.

## Admin
Login → work queue → auction sessions/live ops → payment verification → aggregate reports. Mọi mutation nhạy cảm cần reason và audit event.
